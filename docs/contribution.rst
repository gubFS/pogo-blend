Contributing
============

If you experience any bugs please contact 'thatguyfs' on Discord, either by DM or on the Pogostuck Discord.

If you want to contribute to the codebase or this documentation check out the README on the `GitHub <https://github.com/gubFS/pogo-blend>`__.

If you want to write or record a guide for this documentation, please feel free to do so! If you don't know how to add it on GitHub, let 'thatguyfs' know and I'll add it for you.
