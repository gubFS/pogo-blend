Sap-like Meshes
===============

Here's a little guide if you want to create smooth surface like the ones that are used in the official maps to make sap or ice.

Create a cube and add a Subdivision Surface modifier with the type set to "Catmull-Clark" and a Levels Viewport of 2. You can then extend this cube or loop cut it, and then move around the vertices. Apply shade smooth if you want to see how it would look in-game without the obvious edges. This is how Superku does it, and you can find an example in your Pogostuck installation under ``/Pogostuck/CustomMaps/.WED Files, not a map/Drakula's Castle Source/appendixA28.blend``.
