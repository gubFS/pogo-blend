Tips & Tricks
=============

Here are some handy more niche Blender knowledge that I've gathered while making this add-on.

* You can change the same field on many objects at the same time by holding ALT as you edit the value. This also goes for any of the operators in this add-on, such as the :doc:`Object Tools <objects/object_tools>`
* Use ALT+D to duplicate an object but reuse the mesh.
* Click on the -Y on the gimbal in the top right of the main 3D-view (or NUMPAD1) to enter a sideview similar to what is shown in Pogostuck. Here you can pan around using SHIFT+MiddleMouse. If you spent alot of time in this view you might want to switch the keybind around so just Middle Mouse pans instead of orbits.
* You can use CTRL+ALT+Q to toggle showing a "Quad View", which will show the map on all 3 planes and a perspective view (similar to WED).
* Pressing BACKSPACE on any field will revert it to it's default. If you want to reset the Y-position to 0, you can also click on the Y-value in the location field and select 'Reset Single to Default Value'. If you are doing this often you might want to setup a keybind, like SHIFT+BACKSPACE.
* Enable 'Shade Smooth' on an entity to simulate how it might be displayed in-game.
* SHIFT+RightClick to position your 3D-Cursor. This is the location where new objects will be added.
