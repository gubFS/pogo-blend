Add-on Preferences
==================

You can change various options in the preferences.

The **Custom Maps folder** is the path to folder where the built Custom Maps will be placed.

The **Build on save** option will build the Custom Map whenever you save the Blender file, if enabled. Note: you have to reopen Blender after changing this.

The **Map Scale** value determines the scale that the Custom Map will be exported as. The default value of 50.0 makes it so 2m in Blender is equivalent to the height of the Pogo Dude. It is also the scale at which the generated assets are imported as. I recommend you leave this setting untouched.

The **MDL Exporter/Importer** options, enables exporting and importing MDL-files. The exporter and importer are used internally, but can be made accesible by enabling them here. MDL is the format of models that Pogostuck uses. If you haven't made maps using them before, don't worry about these options.

The **Enable overrides** options, allows you to change all values on an entity. This is mainly for development or for more technical tasks. You can read more about :ref:`overiddes here <overrides>`.
