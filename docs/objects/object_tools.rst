Object Tools
============

PogoBlend includes some tools that might be helpful in speeding up Map creation. You can access the tools under the 'PogoBlend' menu in the Object menu.

Auto Collision
--------------

Creates a collider around the selected object, based on it's sideview, so you don't have to worry about collisions when making your mesh. This is the tool used when the 'Auto Collision' flag is ticked on an entity, so you can use this to either preview the generated collision, or generate and edit it to speed up exporting the map.

Modifiers
---------

Here you can choose some preset modifiers that are often used when making a Custom Map.

Edge Split
^^^^^^^^^^

Meshes in Pogostuck have a smooth look to them by default that you can simulate in Blender by applying Shade Smooth. To get more sharp edges you can use an Edge Split modifier.

Bevel
^^^^^

The original Pogostuck maps uses a Bevel modifier to get defined but still smooth edges.

Presets
-------

You can choose between som presets for commonly used combinations of fields on an entity. Currently it is for:

* Ice
* Sap
* Pink Sap
* Boost Juice
* Background (enables background flag and parallax action)
