Paths
=====

Paths are are series of points connected by lines. 

The only uses for paths are for the progress path, and the paths used with the thorns action.

To create a Path open the add menu and under PogoBlend you can select Path. 

.. caution::

   Any Curve Object in Blender can become a Pogo Path but the builder only uses the points to create the path so curves like Beizer Curves can have deceptive visuals that don't convey what the path will acutally look like in-game. So use the provided way of making paths in the ``Add -> PogoBlend -> Path`` or change the spline type of your Curve to 'Poly'.
