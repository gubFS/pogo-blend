Object Types
============

A Custom Map is made up of regular Blender objects that can have certain 'PogoData' depending on their type.

There are 3 different object types in PogoBlend:

- :doc:`Entity <entity>`
- :doc:`Region <region>`
- :doc:`Path <path>`
