Motivation
==========

The previous way of making Custom Maps was by using really old tools that are not at all specialized to the map making process and had a lot of noise. I wanted to make it easier for anyone to make a map, and make it faster for experienced map makers. My main motivation was also making something that works across platforms, not just on Windows. When I started working on this, I worked for a while on a standalone application, but the more I worked on it, the more I realized I was just trying to remake Blender. So I pivoted and started developing a Blender add-on. The great thing with using Blender is that you can also interface with all the other amazing things that also support Blender, in order to optimize your workflow.
